# NextRAM Manager 2.2

Нативное приложение-компаньон для Magisk-модуля [NextRAM](https://github.com/LineXin/NextRAM).
Без WebView, без AndroidX, без единой зависимости. Весь интерфейс на Java.

## Экраны

| Вкладка | Что внутри |
|---|---|
| Обзор | кольцевой индикатор ОЗУ, состояние root и модуля, плитки ZRAM / Swap, быстрые действия |
| Настройки | все ключи `config.conf` автоматически: переключатели, степперы, текстовые значения; кнопка «Применить» |
| Профили | четыре готовых набора: Экономный, Баланс, Максимум, Игра |
| О нас | Credits (LineXin, Rexamm1t), выбор акцентного цвета из 8 пресетов, данные устройства, ссылка на репозиторий |

## Палитра

Чёрный фон `#0B0B0C`, поверхности `#141416`, волосяная обводка `#26262B`.
Акцент по умолчанию — оранжевый `#FF7A1A`, второй цвет градиента — красный `#E5322B`.
Цвет меняется в разделе «О нас» и сохраняется в SharedPreferences.

## Как читается конфиг

Путь ищется сам: `/data/adb/modules/NextRAM/config.conf`, затем `/data/adb/modules/nextram/config.conf`.
Ключи берутся прямо из файла — список настроек не захардкожен, поэтому новые параметры модуля появятся сами.
При сохранении незнакомые строки и комментарии остаются на месте, запись идёт через base64 в `su`.

## Сборка

GitHub Actions: вкладка **Actions** → **Build APK** → **Run workflow**.
Артефакт `NextRAM-Manager-apk.zip` содержит `app-debug.apk`.

Локально: `gradle assembleDebug`.

Подпись отладочная, пакет `com.nextram.manager`. Старую сборку с другой подписью нужно удалить перед установкой.
